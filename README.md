## 🌟 Highlights & Features

- **Borderless Circular Project Wheel**:
  - Open, high-whitespace wheel interface inspired by Rational Lab.
  - Thin arc guidelines bleeding off-canvas, large typographic indices, and smooth momentum physics.
  - Dynamic detail card with clip-path reveal transitions and responsive aspect-ratio containment.
  - Zero letterboxing whitespace — the container automatically hugs wide, square (1:1), and vertical formats.

- **5-Column Bento Grid ("At a Glance")**:
  - Expanded portrait card with ample breathing space showcasing visual identity.
  - Verified **Adobe Certified Professional** badge (Certport verification: `wL9PR-Fa9D`).
  - Structured skill categories: **Design Tools**, **Video Editing & Generative AI**, and **Web Tech** (with basic understanding indicators).
  - 100% bar-free, interactive tag chip styling.

- **Interactive Gamified Contact Deck**:
  - Physical multi-step stacked cards with 3D perspective layering.
  - Step-by-step interactive quiz deck capturing user details, topics, and inquiries.
  - Review summary with instant editing jumps and celebratory confetti celebration.
  - Direct 1-click delivery via **WhatsApp Web / Mobile** and **Email**.

- **Performance & Aesthetics**:
  - Ultra-smooth inertial scrolling via **Lenis**.
  - Seamless Light / Dark theme switching with `localStorage` memory and OS system preference sync.
  - Zero heavy framework dependencies — pure semantic HTML5, modern CSS3 with custom design tokens, and modular vanilla ES6+ JavaScript.

## 🚀 Running Locally

No build step or Node compilation required. You can run the portfolio directly:

1. **Direct Browser**:
   - Double-click `index.html` or open it with your browser of choice.

2. **Local Development Server** (e.g. VS Code Live Server / Antigravity / Python):
   ```bash
   # Python 3
   python -m http.server 8000
   
   # Node.js npx
   npx serve .
   ```
   Open `http://localhost:8000` in your browser.

## 🔍 SEO & AEO (Answer Engine Optimization)

This site is optimized for traditional search engines (Google, Bing) and next-generation Answer Engines (Perplexity, ChatGPT Search, Claude, Google AI Overviews):
- **JSON-LD Schema**:
  - `Person`: Rich biographical data, credentials, education, and social links.
  - `WebSite`: Publisher and authority metadata.
  - `FAQPage`: Structured questions and answers for direct extraction by AI search engines.
- **Social Metadata**: Open Graph tags and Twitter Cards with optimized `preview.webp`.
- **Bot Accessibility**: Crawling directives in `robots.txt` explicitly permitting PerplexityBot, GPTBot, Claude-Web, and Googlebot.
